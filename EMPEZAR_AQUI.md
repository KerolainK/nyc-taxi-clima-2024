# Empezar aquí

1. Abrir `reports/Memoria_Taxis_Clima_2024.pdf`: explica pregunta, fuentes, limpieza, resultados y límites.
2. Abrir `dashboard/Dashboard_Taxis_Clima_2024.xlsx`: usar los tres selectores amarillos.
3. Abrir `notebooks/EDA_Taxis_Clima_2024.ipynb` en VS Code: contiene siete celdas de código ejecutadas y sus salidas.
4. Leer `reports/Guion_defensa.md`: presentación de 7-8 minutos y respuestas a preguntas habituales.
5. Consultar `README.md` para reproducir el análisis y conocer la organización.

El proyecto incluye el extracto bruto sin limpiar, NOAA original, datos finales, código, notebook, Excel, informe y verificaciones. La publicación en un repositorio GitHub es el último paso externo; no equivale a entregar solamente un ZIP en el campus.
